## 📝 Documentation Standards

### For Contributors
When adding documentation:

1. **Implementation Details** → `/implementation/` - Completed features and implementations
2. **Status Reports** → `/status/` - Current project status and progress
3. **Troubleshooting** → `/troubleshooting/` - Bug fixes and problem resolution
4. **How-To Guides** → `/guides/` - Setup instructions and tutorials
5. **Feature Specs** → `/features/` - Feature documentation
6. **Dev Notes** → `/development/` - Technical implementation notes

### Standards
- Use clear, descriptive headings
- Include code examples where applicable
- Add screenshots for UI documentation
- Keep documentation current with code
- Use consistent markdown formatting
