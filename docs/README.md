## 📝 Documentation Guidelines

### For Contributors
When adding new documentation:

1. **Development Notes**: Add to `/development/` for implementation details, bug fixes, and technical summaries
2. **Feature Documentation**: Add to `/features/` for new features, systems, or major functionality
3. **Guides & Tutorials**: Add to `/guides/` for setup instructions, how-to guides, and reference materials

### Documentation Standards
- Use clear, descriptive headings
- Include code examples where applicable
- Add screenshots for UI-related documentation
- Keep documentation up-to-date with code changes
- Use consistent markdown formatting
